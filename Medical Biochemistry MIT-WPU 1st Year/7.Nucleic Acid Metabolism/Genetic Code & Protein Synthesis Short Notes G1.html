Genetic Code & Inhibition of Protein Synthesis

Comprehensive Biology Notes

Section I: In-Depth Concepts

1. The Genetic Code

The genetic code acts as the dictionary that translates the language of nucleic acids (DNA/mRNA) into the language of proteins (amino acids). A sequence of three adjacent nucleotide bases forms a codon, which specifies a single amino acid.

Key Characteristics

  • ✦
    Number of Codons: There are exactly 64 possible codon sequences. Since RNA uses 4 bases (A, G, C, U) read in triplets, the combination is $4^3 = 64$.
  • ✦
    Stop (Nonsense) Codons: Out of 64, three codons do not code for any amino acid. They act as "stop signs" for protein synthesis.
    UAA (Ochre) | UAG (Amber) | UGA (Opal)
  • ✦
    Degenerate but Unambiguous:
    Degenerate: 61 codons code for only 20 amino acids. This means one amino acid can have multiple codons (Synonyms). For example, Arginine is coded by 6 different codons. This redundancy protects the body from harmful mutations.
    Unambiguous: While an amino acid can have many codons, a specific codon will only ever code for one specific amino acid.
    Exceptions: Methionine (AUG) and Tryptophan (UGG) have only one single codon each.
  • ✦
    Universal (Almost): The code means the same thing in almost all organisms, from bacteria to humans.
    Exceptions (Human Mitochondria):
    • UGA codes for Tryptophan (usually a Stop codon).
    • AUA codes for Methionine (usually Isoleucine).
    • CUA codes for Threonine (usually Leucine).
  • ✦
    Non-overlapping & Punctuation-free: The code is read sequentially, 3 bases at a time, without any gaps.
    Example Sequence: AUGCUAGACUUU
    Is read cleanly as: AUG / CUA / GAC / UUU

2. The Wobble Hypothesis

Proposed by Francis Crick, this hypothesis explains how a single tRNA molecule can recognize and bind to multiple synonymous codons, solving the "degeneracy" puzzle. It relies on the flexibility (wobble) of the 3rd base in the codon.

Example of Wobble: Yeast tRNA for Alanine has the anticodon IGC (I = Inosine). Because of the wobble, this single tRNA can perfectly bind to three different mRNA codons: GCU, GCC, and GCA.

Crick's 4 Rules of Wobble:

Rule 1: Strict Pairing

The first two bases of an mRNA codon always form strong, standard Watson-Crick base pairs with the anticodon.

Rule 2: Distinct tRNAs

Codons that differ in their first or second base must be read by entirely different tRNAs (e.g., UUA and CUA for Leucine).

Rule 3: The Anticodon Factor

The first base of the anticodon dictates the wobble:
• If C or A: Reads 1 codon.
• If U or G: Reads 2 codons.
• If I (Inosine): Reads 3 codons.

Rule 4: Economy of tRNA

Thanks to the wobble effect, a cell doesn't need 61 tRNAs for 61 codons. A minimum of just 32 tRNAs is sufficient to translate all amino acids.

3. Inhibition of Protein Synthesis

Many antibiotics and toxins function by hijacking or blocking specific stages of translation. Most antibiotics selectively target prokaryotic (bacterial) ribosomes without harming eukaryotic (human) cells.

Inhibitor (Antibiotic/Toxin) Target Site Mechanism of Action
Puromycin Prokaryotes & Eukaryotes Mimics 3' end of aminoacyl-tRNA. Gets incorporated into the chain, preventing further addition. Causes premature chain termination.
Tetracyclines 30S Subunit (Prokaryotes) Inhibits binding of the incoming aminoacyl-tRNA to the ribosomal 'A' site.
Chloramphenicol 50S Subunit (Prokaryotes) Blocks the peptidyl transferase reaction (prevents peptide bond formation).
Erythromycin 50S Subunit (Prokaryotes) Inhibits the translocation step (ribosome moving along mRNA).
Streptomycin 30S Subunit (Prokaryotes) Causes misreading of the genetic code and interferes with initiation tRNA binding. Inhibits chain elongation.
Lincomycin & Clindamycin 50S Subunit (Prokaryotes) Inhibits peptidyl transferase, preventing peptide bond formation.
Cycloheximide 60S Subunit (Eukaryotes) Blocks peptidyl transferase activity specifically in eukaryotes.
Diphtheria Toxin Eukaryotes Inactivates the elongation factor, halting protein synthesis.
Tunicamycin Glycoproteins Prevents attachment of oligosaccharide side chains to glycoproteins.

Section II: Quick Revision Notes

Cheat Sheet

🧬 Genetic Code & Wobble

  • 64 Codons Total: 61 code for amino acids, 3 are Stop signals.
  • Stop Codons: UAA, UAG, UGA.
  • Degenerate: Redundancy (multiple codons per amino acid). Minimizes mutation risk.
  • Unambiguous: 1 codon = STRICTLY 1 amino acid.
  • Exceptions to Universal Rule: In human mitochondria, UGA = Trp, AUA = Met, CUA = Thr.
  • Wobble Hypothesis (Crick): 3rd base pairing is loose. Allows a minimum of 32 tRNAs to read all 61 amino-acid codons.

💊 Antibiotics Target Mappings

  • 30S Subunit Blockers: • Tetracycline: Blocks A-site binding.
    • Streptomycin: Causes misreading & inhibits elongation.
  • 50S Subunit Blockers: • Chloramphenicol: Blocks peptidyl transferase.
    • Erythromycin: Blocks translocation.
    • Lincomycin/Clindamycin: Blocks peptide bond formation.
  • Special Cases: • Puromycin: Premature termination (Both Pro/Euk).
    • Cycloheximide: 60S eukaryotic blocker.
    • Diphtheria Toxin: Inactivates eukaryotic elongation factor.
