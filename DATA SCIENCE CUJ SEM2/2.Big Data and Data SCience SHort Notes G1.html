1 Introduction to Big Data & Data Science

Data Kya Hai? (What is Data?)

Basically, data kisi bhi cheez ki raw information hoti hai. Data Science ki duniya mein hum data ko mainly do hisso mein samajhte hain:

  • Objects (Samples, Individuals): Yeh hamara actual data record hota hai (e.g., Student 1, Student 2). Data table mein ye Rows hoti hain.
  • Attributes (Dimension, Features, Variables): Yeh objects ki characteristics hoti hain (e.g., Height, Weight, Age). Data table mein ye Columns hoti hain.

Big Data ke 2 Perspectives (Narrow vs Broad)

Narrow Sense

Ek chhoti soch mein, Big Data ka matlab sirf Sample Size (Rows) ka bada hona hai. Matlab sirf logo ki ginti zyada hona.

Broad Sense

Actual (broad) definition mein, Big Data sirf size nahi, balki Sample Size + Dimensionality (Features/Columns) dono ka combination hai. Data bada bhi hai aur complex (bahut saari properties wala) bhi hai.

3 The 3 V's of Big Data

Big Data is any data that is expensive to manage and hard to extract value from. Iske complexity ko mainly 3 V's se define kiya jaata hai.

1. Volume (Size of Data)

Kitna zyada data hai? Jab data GBs se aage badhkar Terabytes (TB) aur Petabytes (PB) mein chala jaye. Isme shamil hain millions of transactions aur sensor data.

Terabytes Petabytes Transactions

2. Velocity (Speed of Data)

Latency of data processing. Yaani data kis speed se aa raha hai aur usko process karne ki demand kitni tez hai. Speed ka flow kuch aisa hota hai:
Batch -> Periodic -> Near Real-time -> Real Time

Batch Streams Real-time

3. Variety (Complexity of Data)

Diversity of sources aur formats. Pehle data sirf tables (RDBMS) mein hota tha, ab images, videos, logs, XML sab data hain.

RDBMS XML / JSON Audio/Video

4 Different Types of Data We Have

Real world mein data sirf Excel sheets mein limited nahi hai. Chaliye dekhte hain kitne tarah ke data formats exist karte hain:

Structured Data

Rows aur columns mein properly arranged data. Ise analyze karna sabse asaan hota hai.

Examples: RDBMS, SQL Tables, Spreadsheets

Semi-structured Data

Isme strict tables nahi hote, balki "Tags" ka use hota hai elements ko separate karne ke liye.

Examples: XML, JSON, HTML, Linked Open Data (vCards)

Unstructured Data

Koi fix fields ya attributes nahi hote. Ye sabse jyada generate hota hai aaj kal.

Examples: Text (Web), Emails, Notes, Articles, Videos, Tweets

Graph & Network Data

Jahan data points ke beech ke relationships matter karte hain.

Examples: Social Networks, Semantic Web (RDF), IP Connections

Other Specialized Domains:

  • Geospatial Data: Layers mein data manage hota hai (e.g. Street data -> Buildings -> Vegetation -> Integrated Map).
  • Streaming Data: Continuous aane wala data jise aap fast scan karte hain (e.g. Sensors, IP log connections).
  • IoT (Internet of Things) Data: Smart homes, Smart manufacturing (RFID), Wearables, Connected cars, Healthcare remote monitoring. Ye huge volume generate karta hai.
  • Transactional Data: Accounts payable/receivable, Credits, Debits, invoices ki logs (Banking/Accounting).

Math / Units Cheatsheet

$$ 1 \text{ Kilobyte (KB)} = 1024 \text{ Bytes} $$ $$ 1 \text{ Megabyte (MB)} = 1024 \text{ KB} $$ $$ 1 \text{ Gigabyte (GB)} = 1024 \text{ MB} $$ $$ 1 \text{ Terabyte (TB)} = 1024 \text{ GB} $$ $$ 1 \text{ Petabyte (PB)} = 1024 \text{ TB} $$

Fact: 1 Petabyte (PB) = 1,048,576 Gigabytes (GB)

The 3 V's Summary

  • Volume: GBs, TBs, PBs. The scale of data.
  • Velocity: The speed of data generation & processing (Batch to Real-time).
  • Variety: Structured, Semi-structured, Unstructured. The diversity of data.
